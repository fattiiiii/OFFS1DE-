## BACKEND REQUIREMENTS (Dashboard Only)
- Simple database (MongoDB or similar) to store orders
- Order data structure:
  - Order ID (auto-generated)
  - Customer name, WhatsApp, Instagram
  - Products array (product ID, sleeve type, quantity)
  - Total price
  - Order date
  - Status (Pending/Confirmed/Shipped)
  - Notes
- Authentication (simple login for admin)
- API endpoints:
  - POST /orders (create order)
  - GET /orders (fetch all orders)
  - PUT /orders/:id (update order status)
  - DELETE /orders/:id (delete order)
